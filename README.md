# ceo-engineering

Opencode configuration: agents, commands, hooks, loops, plugins, and skills.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/SuyeshBadge/ceo-engineering/main/install.sh | bash
```

Installs into `~/.config/opencode`, backing up any existing config there first
(`~/.config/opencode.backup-<timestamp>`).
